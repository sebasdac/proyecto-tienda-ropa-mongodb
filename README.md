# Proyecto Tienda de Ropa MongoDB

## Descripción

Este proyecto consiste en una base de datos desarrollada en MongoDB para una tienda de ropa.

La base de datos permite manejar información relacionada con usuarios, marcas, prendas y ventas.

También incluye operaciones para insertar, actualizar y eliminar datos, además de consultas para obtener información sobre ventas, marcas y stock disponible.

## Tecnologías utilizadas

- MongoDB
- JavaScript
- GitHub
- Markdown

## Colecciones

El proyecto utiliza las siguientes colecciones:

- usuarios
- marcas
- prendas
- ventas
